Golden windows (tests/fixtures/golden_windows.csv):
  t=2030-02-01T10:00:00 count_30m=3 recency_s=1 label=0
  t=2030-02-01T10:30:00 count_30m=1 recency_s=1800 label=1
  t=2030-02-01T11:00:00 count_30m=2 recency_s=1800 label=0
Why the 10:30 event belongs to the NEXT forecast:
  The target interval is half-open [t, t+30m): an event exactly
  at t belongs to that window's target; an event exactly at t+30m
  belongs to the next target. The 10:30 motion ON (and door OPEN)
  fall at the end of the 10:00 window's target [10:00, 10:30), so
  the 10:00 window has label 0, and the 10:30 window — whose target
  is [10:30, 11:00) — has label 1. History is [t-w, t), so the
  10:30 window's 30-minute history counts the 10:00 OFF (count_30m=1)
  but not the 10:30 events themselves.
